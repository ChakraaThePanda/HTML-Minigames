# HTML-Minigames

A collection of small standalone HTML mini projects/games, each self-contained in its own subfolder (with its full original commit history preserved).

- [Archipelago-Game-Picker](Archipelago-Game-Picker/) — weighted random picker for choosing what game to play next.
- [MTG-Decklists-Game](MTG-Decklists-Game/) — a guessing game built from our past MTG decklists.
- [WTTG-K3RN3LC0MP1L3R-Minigame](WTTG-K3RN3LC0MP1L3R-Minigame/) — practice minigame for Welcome to the Game's K3RN3LC0MP1L3R.
- [Key-Tiles-Game](Key-Tiles-Game/) — reflex game where you clear streaming tiles in the right lane before they hit bottom.

Each subfolder has its own README with more details.
