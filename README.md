# HTML-Minigames

A collection of small standalone HTML mini projects/games, each self-contained in its own subfolder.

- [Archipelago-Picker](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/Archipelago-Picker/Archipelago-Picker.html) — weighted random picker for choosing what game to play next.
- [Key-Tiles](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/Key-Tiles/Key-Tiles.html) — reflex game where you clear streaming tiles in the right lane before they hit bottom.
- [MTG-Decklists](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/MTG-Decklists/MTG-Decklists.html) — a guessing game built from our past MTG decklists.
- [WTTG-K3RN3LC0MP1L3R](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/WTTG-K3RN3LC0MP1L3R/WTTG-K3RN3LC0MP1L3R.html) — practice minigame for Welcome to the Game's K3RN3LC0MP1L3R.

Each subfolder has its own README with more details.
