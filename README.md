# HTML-Minigames

A collection of small standalone HTML mini projects/games, each self-contained in its own subfolder (with its full original commit history preserved).

- [Archipelago-Game-Picker](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/Archipelago-Game-Picker/Archipelago-Game-Picker.html) — weighted random picker for choosing what game to play next.
- [MTG-Decklists-Game](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/MTG-Decklists-Game/MTG%20Guessing%20Game.html) — a guessing game built from our past MTG decklists.
- [WTTG-K3RN3LC0MP1L3R-Minigame](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/WTTG-K3RN3LC0MP1L3R-Minigame/K3RN3LC0MP1L3R.html) — practice minigame for Welcome to the Game's K3RN3LC0MP1L3R.
- [Key-Tiles-Game](https://htmlpreview.github.io/?https://github.com/ChakraaThePanda/HTML-Minigames/blob/main/Key-Tiles-Game/key-tiles-game.html) — reflex game where you clear streaming tiles in the right lane before they hit bottom.

Each subfolder has its own README with more details.
